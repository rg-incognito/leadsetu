# 2026-08-31 — Setup session (not a nightly run)

Owner asked for an autonomous nightly "company" that builds and sells a product overnight
(1am-10am IST), logging state so the next session can resume with no hand-holding.

## Decisions made this session
- **Architecture:** cloud-based, not laptop-based. A cloud routine (claude.ai/code routine) fires
  nightly, pulls this GitHub repo, does the work, commits + pushes logs. The owner's laptop is not
  part of the infra — no ports opened on it, ever (see `POLICY.md`).
- **Hosting:** Vercel free tier for anything that needs to be publicly reachable.
- **Outreach:** auto-send authorized by owner, but capped at 15 cold emails/night sent from the
  owner's real Gmail via an authenticated Gmail MCP connector, specifically to avoid getting the
  owner's personal Gmail flagged/suspended for bulk sending. This cap is a safety decision made
  unilaterally this session under the "attend to risk even when told to act autonomously"
  principle — raising it needs the owner's explicit sign-off.
- **Niche (v1):** lead-capture + auto-follow-up service for Indian small/local businesses.
  Reasoning: low build complexity (form + sheet + email), sellable via cold outreach (fits the
  owner's request to "reach out to clients"), no per-client infra cost if built on Vercel free
  tier + Google Sheets, and addresses a real, common pain point (missed leads) that's easy to
  explain in one sentence to a non-technical shop owner.
- **Token budget:** ~300K tokens/night target, conservative, to give a long runway against the
  session's overall budget.
