# LeadSetu — Candidate Target Businesses (Research Pass 1)

**Purpose:** Candidate list of small, independently-run Indian local businesses for LeadSetu's
"lead-capture + auto-follow-up" pitch. Target profile: solo/small-team operations in
categories that field enquiries by phone, WhatsApp, or a basic website contact form, with no
visible sign of a CRM or dedicated front-desk/enquiry-handling system — i.e. businesses that
plausibly let a Saturday-evening enquiry go unanswered. Large chains and multi-city franchises
(Anytime Fitness, Lakme Salon, VLCC, Reliance Digital, Aakash Institute, Tattva Spa, etc.) were
deliberately excluded from this list even when they surfaced in search, since they typically
already run enterprise CRM/enquiry systems.

**Sourcing method:** Businesses were found via targeted web search (Google-indexed business
websites, Facebook business pages, and public directory listings — JustDial, Sulekha, IndiaMART).
For each entry, the contact email listed is one that appeared as literal, visible text on the
business's own website or on a public directory listing page — never inferred or pattern-guessed
(e.g. no "info@businessname.com" guesses). Several businesses' sites use email-cloaking
(Cloudflare-style "protected" placeholders) that could not be resolved to a real address from
search results alone — these are marked "none found — phone/form only" rather than guessed.
The exact page each email/contact was seen on is in the Source URL column so it can be
re-verified before anyone sends anything. Cities deliberately skew tier-2/tier-3 (Indore, Nagpur,
Coimbatore, Jaipur, Lucknow, Surat, Bhopal, Nashik, Vadodara, Kanpur, Dehradun, Mysore, Guwahati,
Ranchi, Bhubaneswar) to avoid the Mumbai/Delhi/Bengaluru businesses that bigger outreach/CRM
vendors already saturate.

**Status:** 29 businesses total. **25 have a verified, publicly-visible email address** usable
for outreach tonight; 4 have phone/contact-form only and are listed for future
phone/WhatsApp-based outreach, not tonight's email run.
