# LeadSetu — Candidate Target Businesses (Research Pass 2, 2026-09-01 night 2)

**Purpose:** Second batch of candidate small Indian businesses for LeadSetu's outreach,
found after research pass 1 (`targets.md`) was fully exhausted. Same target profile and
sourcing rules as pass 1 — see that file for the full method description. Cities were
deliberately chosen to NOT overlap pass 1's list (Indore, Nagpur, Coimbatore, Jaipur,
Lucknow, Surat, Bhopal, Nashik, Vadodara, Kanpur, Dehradun, Mysore, Guwahati, Ranchi,
Bhubaneswar).

**Sourcing method:** WebSearch only (WebFetch to arbitrary external domains is blocked in
this sandbox). Every email listed appeared as literal visible text in a search-result
snippet from the business's own site, a Facebook page, or a public directory listing
(JustDial, etc.) — never guessed. Three initially-surfaced emails failed a second
verification pass and were dropped rather than risk a wrong-recipient send (an email that
actually belonged to an unrelated business, one with zero independent confirmation, and
one that matched an ambiguous same-named business) — details in git history of the
research agent's report if ever needed.

**Status:** 20 businesses total. **18 have a verified, publicly-visible email address.**
2 have phone/form only (see bottom table) — future phone/WhatsApp outreach candidates,
do not guess an email for them.
